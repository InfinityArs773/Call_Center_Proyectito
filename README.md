# Call_Center_Proyectito 
# EricKLF

La llamadas no se atienden por arte de magia. Bueno técnicamente si se pude, solamente si ejecutas el método correcto. 😸📞☕

En este pequñisimo programita se implementa una **cola genérica mediante nodos en Java** para gestionar llamadas normales y prioritarias, practicar estructuras de datos y llevar las cuentas de la atención.

## ¿Qué incluye?

- `enqueue()` y `dequeue()`: agregar y retirar llamadas.
- `peek()`, `empty()` y `size()`: consultar el estado de la cola.
- `enqueuePrioritario()`: porque hacer fila es opcional, aparentemente.
- Atención, cancelación y estadísticas de llamadas.

  Hecho en Java, con nodos y rezar para que todo compile como debe ser. 😿🙏☕
